# HTsummer0908.github.io

> 个人主页仓库 · Personal GitHub Pages source

## 说明

这是 [@HTsummer0908](https://github.com/HTsummer0908) 的个人主页源码仓库。

| 文件 | 说明 |
|------|------|
| `index.html` | 个人主页页面（纯 HTML + CSS，无外部依赖） |

## 使用

- 如需公开展示，将仓库可见性改回 **Public**，GitHub Pages 会自动部署至 `https://HTsummer0908.github.io`
- 如使用 GitHub Pro，Private 仓库也可开启 Pages

## 自定义

编辑 `index.html` 中以下部分：

```html
<!-- 个人简介 -->
<p class="bio">你的简介</p>

<!-- 技术标签 -->
<span class="tag">你的技术栈</span>

<!-- 链接 -->
<a href="...">你的链接</a>
```
